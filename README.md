# Saikit-learn

Biblioteca com ferramentas de aprendizado de máquina, desenvolvida como projeto final da disciplina de Aprendizado de Máquina I do IMPA Tech.

## Instalação

Para instalar a biblioteca, execute:

```bash
pip install saikit-learn
```

## Funcionalidades

A biblioteca reúne implementações de algoritmos de aprendizado de máquina e ferramentas relacionadas, com o objetivo de facilitar sua utilização e experimentação.
